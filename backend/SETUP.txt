SETUP BULETIN JUMAT AT-TAUBAH v2.0

1. Buka Google Apps Script yang terhubung dengan Spreadsheet.
2. Tempel seluruh isi backend/Code.gs.
3. Simpan.
4. Jalankan fungsi setup() sekali.
5. Jalankan fungsi authorizeDrive (jika tersedia/ditambahkan) atau kirim satu file Word dari form untuk memicu permintaan izin Drive.
6. Project Settings > Script Properties:
   ADMIN_USER = admin
   ADMIN_PASSWORD = AtTaubah@2026!

Opsional publish otomatis ke GitHub:
   GITHUB_TOKEN = token GitHub
   GITHUB_OWNER = dkm-at-taubah
   GITHUB_REPO = buletin-jumat
   GITHUB_BRANCH = main

7. Deploy > New deployment / Manage deployments > Web app.
   Execute as: Me
   Who has access: Anyone
8. Gunakan URL /exec yang sama di Admin.

Alur:
DRAFT -> Kirim ke Pengurus -> REVIEW PENGURUS -> (Perlu Revisi / Disetujui) -> Terbit.

Link review memakai token unik per edisi. Halaman review menampilkan watermark DRAFT — REVIEW PENGURUS.
Pengurus dapat menyetujui atau mengembalikan dengan catatan. Edisi publik hanya boleh terbit setelah status approved.

Form publik hanya menerima Word .doc/.docx maksimal 5 MB. File disimpan di Google Drive dan metadata masuk ke SUBMISSIONS.
